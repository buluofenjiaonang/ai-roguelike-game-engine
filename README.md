An HTML5 2D action roguelike game featuring dynamic combat, procedural abilities, and permanent progression
# 肉鸽无尽 (Havoc in Heaven - Roguelike)

A feature-rich HTML5 2D action roguelike game built with vanilla JavaScript and Canvas API. This game was developed with the assistance of powerful AI coding agents, showcasing efficient human-AI collaboration in building complex, interactive front-end applications and designing sophisticated game logic and state management.

## ✨ Key Features
- **Dynamic Combat System**: Includes multi-hit combos, 5 unique skills (Sky Sword, Orbiting Blades, Diamond Body, Freeze, Bloodlust Blade), and dash mechanics.
- **Deep Roguelike Mechanics**: 42 upgradable abilities across 4 rarities. Build your character differently each run.
- **Procedural Stages**: 4 handcrafted stages with wave-based enemy spawning, diverse enemy types, and challenging multi-phase bosses. Infinite cycling with increasing difficulty.
- **Advanced Visual Effects**: Particle systems, screen shake, hit-stop effects, and dynamic lighting for a polished game feel.
- **Game State Management**: Robust state machine handling menus, gameplay, pause, ability selection, and game-over screens.
- **Persistent Progression**: Automatic saving system that preserves character growth (level, gold, abilities) across runs, even after death.

## 🛠️ Tech Stack
`JavaScript` `HTML5 Canvas` `CSS3` `Web Audio API` `LocalStorage`

## 🎮 How to Play
1. Clone the repository or download the `rogue_infinite.html` file.
2. Open `rogue_infinite.html` in any modern web browser.
3. Check the in-game "Controls" screen for full key bindings.

## 🤖 AI-Assisted Development
This project was built with the significant help of AI coding agents. The development process involved:
- **Agent-Assisted Architecture**: LLM Agents helped design the modular game state system, ability framework, and wave-based spawning logic.
- **Programmatic Art Generation**: All visual effects, UI elements, and character designs were coded programmatically with the assistance of AI.
- **Efficient Prompt Engineering**: Complex features like the 42-ability system and boss phase transitions were implemented through iterative prompting and AI-assisted debugging and architecture.
